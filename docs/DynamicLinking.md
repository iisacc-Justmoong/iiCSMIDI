# 동적 라이브러리 빌드

MIDI 모듈은 기본적으로 공유 라이브러리로 빌드하며 `BUILD_SHARED_LIBS=OFF`로
정적 빌드를 선택한다. iOS에서는 프레임워크, WebAssembly에서는 사이드 모듈로
빌드한다. 공개 CMake 타깃과 앱의 명시적 파일·런타임 조합 계약은 유지한다.

테스트는 대상 유형과 소비자 연결 및 MIDI 기능을 검사하며 앱을 실행하지 않는다.

Emscripten 소비자 설정은 공유 사이드 모듈을 가져오기 전에 CMake의 공유 라이브러리 지원을 활성화한다. 앱의 메인 모듈 컴파일·링크 옵션은 빌더 또는 앱이 지정해야 한다.
